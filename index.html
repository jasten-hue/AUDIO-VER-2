Model Upper / Lower Limit Settings

Edit the upper (UL) and lower (LL) limit breakpoints used for each product model, or add a new model with its own limits. Values are compared against the CSV/log data at each listed frequency (Hz) and linearly interpolated in between. The first row must stay Hz,Spk_FR_LL,Spk_FR_UL,Spk_RB_UL,Spk_THD_UL,Mic_FR_LL,Mic_FR_UL,Mic_Seal_LL,Mic_Seal_UL,Mic_THD_UL — leave a value blank for "not tested" at that frequency.

Fetch Logs by SN

Searches every work order / station folder on the server and downloads any matching .7z file(s), extracts the images inside them, and removes the .7z. Images that were already fetched are not downloaded again. This does not load anything into the analyzer.
Click a file to view its images.
